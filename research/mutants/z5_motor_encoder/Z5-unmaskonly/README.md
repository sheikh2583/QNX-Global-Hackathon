# Z5-unmaskonly

**Truth: bad.** The interrupt is unmasked before the 2 ms recompute, which still runs in the IST at priority 60.

**Why.** Edge case, truth preregistered after reasoning: the line is masked for less time, but at about 2,700 interrupts/s (one per 0.37 ms) a 2 ms recompute in the IST still cannot keep up, so events coalesce and the thread still starves everything below 60 on CPU 0. Judged 'bad' (a partial fix at best).

**Tests.** Edge case where the finding definition (masked time) and the real harm (IST starvation) differ.

**Base.** bugzoo/z5_motor_encoder/main.c. Apply `patch.diff` with `patch -p1` to a copy of the base file.
