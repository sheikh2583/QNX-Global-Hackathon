## Rules for this draft

- **No hand-typed numbers.** Every result comes from `docs/research/numbers.tex` (generated by
  `research/make_numbers.py`). A number that has no macro yet is written `\needmacro{Name}{value}`: it renders in orange
  and is listed in the log. Before submission there must be **zero** `\needmacro` and **zero** `\pending`.
  Main Build adds each requested macro to `make_numbers.py`.
- `\pending{...}` marks text that waits on an experiment (R2, R3, R5, R8-VM).
- `\fixme{...}` marks a known problem to fix before submission.
- Claims must match `docs/research/CLAIMS.md`: only "supported" rows may be stated without qualification.
- Anonymity: the tool name is the macro `\tool`. If ISSTA 2027 is double-blind **(verify)**, set `\anontrue`, and point
  the artifact link at an anonymised mirror, not the public GitHub repository (which names the user).
- Citations: only entries marked opened or search-only in `docs/research/RELATED_WORK.md`. The classical statistics
  references (Mann-Whitney 1947, Holm 1979, Clopper-Pearson 1934, Sen 1968) are standard but still need a register entry.
